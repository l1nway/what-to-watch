# Cloud Functions

Firestore-триггеры и callable-функции проекта. Регион всех триггеров — `europe-central2`.

## list-updated-tracking

Поле `lists/{listId}.updated` — серверная отметка времени последнего действия со списком. Пишется **только бэкендом**, фронтенд его не трогает и не читает.

Отметка обновляется, если изменилось хоть что-то из «отслеживаемой подписи» документа списка:

- `name` (создание и переименование),
- `groupId` (список добавлен в группу / убран из неё / группа удалена),
- `movies` — множество фильмов, нормализованное как `id:type:status` и отсортированное (добавление, удаление, смена статуса фильма).

Функции:

- `onListActivity` (`lists/{listId}`) — основной триггер. Сравнивает подпись `before` и `after`; если они совпадают, выход без записи. Это и есть защита от бесконечного цикла: собственная запись `updated` подпись не меняет, поэтому повторный запуск триггера сразу завершается. Удаление списка отметку не пишет.
- `onGroupListsActivity` (`groups/{groupId}`) — подстраховка на случай записи, которая меняет только массив `groups.lists`, не трогая `lists.groupId`. Штампует все списки, появившиеся в массиве или исчезнувшие из него. Если такая запись идёт в одном батче с обновлением `lists.groupId`, список может быть проштампован дважды — это безопасно, лишняя запись подпись не меняет.

Инварианты:

- Оба триггера объявлены с `retry: true`, поэтому при сбое событие доставляется повторно — отметка не теряется.
- Значение — `FieldValue.serverTimestamp()`, то есть абсолютный момент времени (Firestore `Timestamp`, UTC). Он не зависит ни от часового пояса клиента, ни от его системных часов; при чтении форматируется под нужный пояс.
- Список, удалённый между событием и записью, приводит к ошибке `NOT_FOUND` (код 5) — она гасится, остальные ошибки пробрасываются, чтобы сработал retry.

## Остальные функции

- `onUserCreate` — создаёт документ `users/{uid}` при регистрации.
- `onGroupSync` — синхронизирует массив `users/{uid}.groups` с `groups/{groupId}.members`.
- `searchMovies`, `getMovieDetails` — прокси к TMDB (секрет `TMDB_KEY`).
- `getAiRecommendations` — подбор похожих фильмов через Gemini (секрет `GEMINI_API_KEY`) с недельным кэшем в `movie_recommendations_cache`.
